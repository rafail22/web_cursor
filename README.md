# ⚡ Web Cursor - 11 Interactive Web Experiences & Rage Games

Koleksi 11 aplikasi web dan game mikro interaktif unik yang dibangun dengan **HTML5, CSS3, Vanilla JavaScript**, dan **Web Audio API** prosedural (100% offline & zero dependencies).

---

## 🎮 Daftar 11 Game & Web Experience

### 🔥 Zona Game Bikin Kesel & Darah Tinggi (9 Game):
1. **[Tombol yang Mustahil Diklik](button-game.html)**: Tombol hadiah Rp 1 Miliar yang selalu melesat menghindar, balon sindiran pedas, dan Rage Meter dengan goncangan layar.
2. **[Bertahan Sampai Gajian](payday-survival.html)**: Simulator kartu swipe ala Tinder melewati 30 hari godaan finansial dengan saldo Rp 15 Juta.
3. **[The Impossible Password](password-game.html)**: Formulir kata sandi paling nyebelin: jumlah angka harus pas 25, nama hari bahasa Latin, angka Romawi, fase bulan, hingga larangan huruf 'A'!
4. **[Labirin Senggol Bacok](maze-game.html)**: Arahkan kursor melewati lorong kawat sempit tanpa menyentuh dinding listrik. Lengkap dengan laser bergerak, angin virtual, dan tombol Finish yang kabur!
5. **[Kuis Jebakan Batman](quiz-game.html)**: The Impossible Quiz versi Indonesia: 8 soal receh dengan logika di luar nalar, 3 nyawa, bom waktu 10 detik, dan tombol jebakan kamuflase.
6. **[Simulator Batalin Langganan](unsubscribe-game.html)**: Parodi mimpi buruk membatalkan langganan: tombol batal transparan, checkbox negasi ganda, guilt-trip kucing menangis, hingga chatbot CS antrean 1.428.
7. **[Flappy Kursor: Fisika Terbalik](flappy-game.html)**: Karakter melayang ke ATAS secara alami, klik mouse / spasi menukik tajam ke BAWAH, ditambah pop-up notifikasi palsu!
8. **[Uji Refleks Koboi Cabut Pistol](cowboy-game.html)**: Duel koboi satu lawan satu! Waspada jebakan aba-aba palsu (*"KUNING!"*, *"DOR... eh belum!"*). Tembak sebelum aba-aba hijau = tembak kaki sendiri!
9. **[Parkir Paralel Paling Mustahil](parking-game.html)**: Parkir mobil sedan ke slot sempit antara dua Lamborghini. Kemudi terbalik (kiri belok kanan), aspal licin es, dan sopir taksi di belakang klakson tiada henti!

### ⚡ Zona Sistem Operasi & Estetik Futuristik (2 Aplikasi):
10. **[Retro Terminal OS](terminal.html)**: Antarmuka hacker tahun 90-an dengan scanlines tabung CRT, jam digital, baterai, perintah CLI lengkap (`help`, `cat bio.txt`, `projects`, `matrix`), dan suara mechanical keyboard.
11. **[Portofolio Streetwear Cyberpunk](cyberpunk-portfolio.html)**: Portofolio brutalist masa depan dengan aksen acid-lime, canvas foto glitch interaktif, live pemutar musik lo-fi synthwave dengan visualizer real-time, dan custom crosshair cursor.

## 🚀 Cara Menjalankan Secara Lokal

Cukup buka file `index.html` di browser apa saja, atau jalankan melalui web server lokal seperti Laragon / Live Server:

```bash
http://localhost/web_cursor/
```

Semua aset font, audio sintetis, dan efek visual berjalan secara mandiri tanpa memerlukan npm install atau build tools!
